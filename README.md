# Rezume

Генератор резюме для программиста. 5 стилей: неон, гейм-пиксели, Apple, Gemini, обычный.

## Запуск
```
python3 -m http.server 3000
```
Открыть http://localhost:3000

## Деплой
Статика — заливается на Vercel как есть (без сборки).

## Возможности
- Редактор слева, живое превью А4 справа
- Навыки с уровнями, проекты с тегами, опыт/образование
- Автосохранение в localStorage, экспорт/импорт JSON
- Печать в PDF (Ctrl+P) с сохранением стиля
