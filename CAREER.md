# Карьерный разбор: frontend-разработчик (Junior → Middle)

## 1. Плюсы и минусы профиля

### Сильные стороны
| Что | Почему это ценно для работодателя |
|---|---|
| React + TypeScript, реальная архитектура | Ты не просто «делала туториал»: Container/Presentational, Lifting State Up, Context API, типизированные пропсы — это язык, на котором говорят на собесах |
| Fullstack-элементы | Serverless-функции на Vercel, Supabase/PostgreSQL, скрытие ключей в env — половина джунов этого не умеет |
| Деплой и CI/CD | Проекты живые по ссылке. HR/тимлид открывает и видит результат за 10 секунд |
| 4 года преподавания | Коммуникация, объяснение, документация, наставничество джунов. Это прямой путь в Middle и в роли типа «фронт + работа с заказчиком» |
| Дизайн: Figma, Krita, анимации, насмотренность | Редкий гибрид. Ты можешь сделать продукт красивым без дизайнера — для продуктовых команд и студий это сильный аргумент |
| Опыт с C#/Unity/C++/Python | Показывает, что ты быстро учишь языки и понимаешь программирование, а не только JSX |

### Слабые места (и что с ними делать)
| Проблема | Решение |
|---|---|
| Асинхронность (useEffect + таймеры) плавает | Разобрать 3 вещи: замыкания в setTimeout, функция очистки, массив зависимостей. Сделай себе мини-шпаргалку в README проекта |
| TypeScript «на ощупь» | Выучить 6 конструкций: `interface`, union-типы, generics в `useState<T>`, `type` vs `interface`, `as const`, типизация событий (`React.ChangeEvent<HTMLInputElement>`) |
| Нет тестов | Добавить 3–5 тестов на Vitest + Testing Library в LexiCard. Даже минимум резко повышает доверие |
| Нет коммерческого опыта в вебе | Компенсируется: фриланс 2–3 мелких заказа, стажировка, open-source PR. И формулируй преподавание как опыт работы — это реальные 4 года |
| Много разрозненных технологий | В резюме не распыляйся: заголовок строго «Frontend-разработчик (React, TypeScript)». Остальное — в конец, как дополнительное |

## 2. Что учить дальше — по колонкам приоритета

### 🔴 Колонка 1: Must have на Junior+/Middle (учить сейчас, 1–2 месяца)
| Тема | Зачем | Как проверить, что выучила |
|---|---|---|
| TypeScript уверенно | Почти все вакансии Middle требуют | Перевести EduQuiz Pro с JS на TS полностью |
| React-роутинг (React Router) | Есть в 90% вакансий | Добавить в LexiCard страницы `/`, `/learn`, `/stats` |
| Запросы: TanStack Query (React Query) | Кэш, загрузки, ошибки «из коробки» | Заменить ручные `fetch` + `isLoading` в LexiCard |
| Состояние: Zustand (или Redux Toolkit) | Спрашивают на каждом собесе | Вынести настройки и словарь из App.tsx в стор |
| Git flow командный | Ветки, PR, ревью, конфликты | Вести разработку через feature-ветки и PR к себе же |
| Тесты: Vitest + Testing Library | Отличает «пишет код» от «пишет надёжный код» | Тесты на проверку ответа и таймер |
| Основы JS-собеса | Замыкания, event loop, промисы, `this`, иммутабельность | Уметь объяснить вслух за 2 минуты |

### 🟡 Колонка 2: Сильно повышает конкурентоспособность (2–4 месяца)
| Тема | Зачем |
|---|---|
| Next.js (App Router) | Топ-1 требование в вакансиях React сегодня: SSR, роутинг, API-routes. Vercel ты уже знаешь |
| Производительность React | `useMemo`, `useCallback`, `React.memo`, почему ре-рендер — вопрос на любом Middle-собесе |
| Работа с формами: React Hook Form + Zod | Валидация в реальных проектах делается так |
| Tailwind CSS | Де-факто стандарт в новых проектах |
| Доступность (a11y) и семантика | Твоя педагогика + a11y = сильная UX-позиция |
| Vitest/Playwright e2e | Один e2e-сценарий «прошёл тест до конца» смотрится очень взросло |
| Bootstrap + базовый PHP | Ты сама указала целевые вакансии — закрой за 2 недели по верхам, этого хватит |

### 🟢 Колонка 3: Приятный бонус / точки роста на будущее
| Тема | Зачем |
|---|---|
| PWA (manifest + service worker) | Твой план по LexiCard — отличная фича, «устанавливается на телефон» звучит вау |
| Framer Motion | Твоя насмотренность в анимациях + библиотека = вау-эффект в портфолио |
| Storybook | Показывает системное мышление о компонентах |
| Docker (база) | Просят в вакансиях «fullstack-ish» |
| Node.js / Express базово | Чтобы серверные функции перестали быть магией |
| Английский (чтение доков + собес small talk) | Прямо влияет на вилку |

## 3. Как оформить портфолио

### Структура (3 проекта, не больше)
1. **LexiCard** — флагман. React + TS + AI + serverless. Ставь первым.
2. **EduQuiz Pro** — показывает архитектуру и работу с состоянием (после миграции на TS — вообще отлично).
3. **Wedding Invite** — показывает дизайн, анимации и работу с БД.

Поиск фильмов — убери или в одну строку. Слабые проекты снижают общее впечатление.

### Что должно быть в КАЖДОМ репозитории
- [ ] Живая ссылка на Vercel в описании репозитория (поле About) — HR не будет собирать локально.
- [ ] README с: скриншот/GIF в самом верху → что это → стек → фичи списком → архитектура (почему так) → как запустить → чему научилась.
- [ ] GIF-демка (запиши экран, ты умеешь монтировать — это твоё преимущество).
- [ ] Чистые коммиты: `feat: add timer`, `fix: clear timeout on unmount`.
- [ ] Никаких ключей в коде, `.env.example` в наличии.
- [ ] Закреплённые (pinned) репозитории в профиле GitHub + описание профиля.

### Портфолио-сайт
Одна страница на Next.js/Vite: hero с фото и оффером, 3 карточки проектов (скрин, стек-теги, кнопки «Демо» и «Код»), блок «Обо мне» с историей «педагог → разработчик», навыки, контакты. Деплой на Vercel, домен вида `имя.vercel.app`.

## 4. Как подготовиться к поиску работы

1. **Резюме** — этот генератор. Одна страница, стиль «Apple» или «Обычный» для hh, «Gemini» для креативных студий. Формулируй достижениями: не «делала таймер», а «реализовала таймер с корректной очисткой эффектов, устранив утечки при размонтировании».
2. **Сопроводительное письмо** — 5 строк: кто я, ссылка на живой проект, почему именно эта компания, что умею полезного сразу, контакты.
3. **История перехода** — отрепетируй ответ «почему ушла из преподавания»: не «надоело», а «хочу строить продукты, которыми пользуются; педагогика дала мне понимание пользователя и умение объяснять».
4. **Подготовка к собесу**: 20 типовых вопросов по JS/React, рассказ о проекте на 3 минуты, разбор своего кода вслух, простые задачи на массивы/строки.
5. **Каналы поиска**: hh.ru, Хабр Карьера, getmatch, Telegram-каналы вакансий, LinkedIn. Откликайся на 5–10 вакансий в день, включая «Junior» и «без опыта, но с портфолио».
6. **Синдром самозванца**: у тебя fullstack pet-проект с AI-интеграцией и 4 года работы с людьми. Это выше среднего джуна. Ошибки в хуках делают и мидлы — это часть профессии, а не приговор.
